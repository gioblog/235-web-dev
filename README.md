# 235 Intro To Web Tech 
In this repo are all projects I created and homework I worked on during my Fall 2025 semester at RIT. Below I've highlighted the projects that have strengthen my skills in using APIs, Javascript, HTML, & CSS. 

## Project 1 - Reimagining Physical Media Into A Digital Experience
In this project I recreated the layout of a physical magazine page digitally. For the content, I made it be the website of a news media outlet from my own sci-fi world. To start the project, I made the physical page its own digital page (spec.html). Then, I reused the code to for my content to have the same layout. On the website, the model featured was a personal 3D model I made a few years back. Additionally, the small animation of the robot was drawing I made myself :D

## Project 2 - Rick & Morty API Site 
This project was a Javascript driven Web service utilizing a Web API. I chose to use a Rick & Morty API because it is one of my favorite shows ever. The site I made allows users to search up characters in the show. You can also use filters to have more data on the character display. For example the character's life status or their species.
